# 隐私

## 数据流

上传文件从浏览器发送到 Posit Connect Cloud 实例。应用把它们复制到
`tempdir()/session$token/`，只解析该会话副本。不使用账号、数据库或跨会话缓存。

## 保留

会话目录在 `onSessionEnded()` 中删除。实例重启与重新部署也会清空本地文件系统。
应用不提供恢复上次会话上传或结果的方式。请在关闭页面之前下载产物。

## 日志

服务器日志可能记录错误堆栈、文件名与请求元数据。应用不会打印文件内容、完整
tips 列表或用户路径。展示给用户的错误信息会把临时路径替换为 `<tmp>`。请勿在
文件名或上传内容中放置敏感信息。

## 本地替代

数据不能离开本机时，请安装本包并在自己的机器上运行 `mcmctreer::run_app()`。
本地与线上使用同一代码路径，只有托管层不同。
