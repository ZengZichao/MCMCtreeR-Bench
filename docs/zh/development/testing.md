# 测试

## 单元测试

单元测试覆盖：

- `tipDes()` 的 list/vector 归一化与非法节点；
- 绘图坐标到节点编号的映射；
- 逐节点参数构造与分布矩阵；
- 输入哈希的稳定性与敏感性；
- 参数校验与范围检查；
- 会话工作区隔离、文件名安全与路径断言；
- 上传、树、后验、对象与图像限额；
- 错误脱敏与已知警告分类；
- PDF、PNG、SVG 导出、页数与设备清理；
- 双语键对齐与会话级语言状态。

## 集成测试

集成测试把非 gamma 方法的界面估计与上游 `MCMCtreePhy()` 参考逐字段比较，gamma
则直接调用 `estimateGamma()`。测试还用内置数据覆盖模块 B 的三条数据路径。

```r
pkgload::load_all()
testthat::test_local()
```

## 应用冒烟测试

`shiny::testServer()` 驱动示例流程：载入树、添加节点、填写年龄、运行估计、
打开导出步骤，并验证后续输入变化会把结果标记为过期。第二个冒烟测试把 FigTree
数据源载入模块 B。

## 文档门禁

`test-docs_parity.R` 检查 `docs/en` 与 `docs/zh` 路径一致、标题数量一致、代码围栏
一致、内部链接可解析，且没有占位文本。`mkdocs build --strict` 是第二道门禁。

## 浏览器矩阵

发布前测试 Chrome、Safari 与 Firefox，亮色与暗色，中文与英文，以及两个并发无痕
会话。确认上传不串会话，下载使用 ASCII 文件名。
