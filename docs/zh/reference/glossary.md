# 术语表

## 术语

| 术语 | 含义 |
| --- | --- |
| 标定节点 | 年龄由化石或其他证据约束的内部节点 |
| tip | 末端分类单元；本界面不允许把 tip 作为标定节点 |
| 内部节点 | 至少有一条后代边的节点；ape 在 tips 之后编号 |
| `monoGroups` | 定义每个标定 clade 的后代 tip 名称列表 |
| 先验 | MCMC 分析之前放在节点年龄上的分布 |
| 后验 | 贝叶斯分歧时间分析得到的节点年龄样本 |
| HPD | 最高后验密度区间 |
| FigTree 输出 | `readMCMCtree()` 解析的 MCMCtree 制表符树导出 |
| 过期结果 | 输入哈希与当前输入不再匹配的估计结果 |
| 印刷主题 | 白底黑线，用于所有 PDF 导出 |

## 记号

- `Ma` 表示百万年前。
- `tL` 与 `tU` 是 MCMCtree 标签中的年龄下界与上界。
- `pL`、`pR` 与 `pU` 是 MCMCtree 标签中的尾概率。
- `node_1`、`node_2` 是上游参数矩阵的行名；界面在自己的表格中把它们映射回 ape
  节点编号。
