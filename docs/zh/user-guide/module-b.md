# 模块 B：时间树可视化

模块 B 用于可视化时间标定树。它采用单页加折叠设置的形态，因为用户需要在调整
外观时快速、反复地看到结果。

## 分析类型

| 类型 | 需要提供 | 说明 |
| --- | --- | --- |
| MCMCtree | FigTree 输出，或一棵树加后验表 | `build tree` 会用后验平均年龄替换分支长度 |
| MrBayes | `.con.tre` 加 `.run1.t`，可再加后续 run | 文件名会被保留 |
| RevBayes | 一个 `.nex`/`.nexus` 加至少一个 `.trees` | 文件保存在同一会话工作区 |
| User | 时间树加节点年龄表 | 表必须覆盖所有内部节点 |

## 数据要求

后验表为制表符分隔，包含 `t_n1`、`t_n2` 等列。校验后其他列会被忽略。节点年龄
表第一列名为 `node`，其余列为数值样本；也支持 `node` 与 `age` 两列的长表。

MrBayes 上传必须恰好包含一个以字面量 `.con.tre` 结尾的文件，以及匹配的
`.run1.t`。RevBayes 上传必须恰好包含一个 `.nex`/`.nexus`，以及至少一个
`.trees` 文件。

## 绘图类型

- `phylogram` 绘制以年龄为分支长度的时间树。
- `cladogram` 仅适用于 MCMCtree 分析。
- `distributions` 在内部节点绘制后验密度；MCMCtree 或 User 数据需要后验样本。

## 绘图设置

设置分为数据源、绘图类型、地质时间尺、节点不确定性、树外观、分析设置与导出。
只显示与当前分析类型相关的参数。留空的颜色会跟随当前绘图主题；PDF 始终使用
印刷主题。

地质时间尺支持 Eon、Period、Epoch 与 Age。选择多个层级时会从下到上堆叠。绝对
年龄可以添加到最后一个层级。

## 自动与手动重绘

小数据会在短暂防抖后自动重绘。后验超过 100,000 行时，应用默认切换为手动重绘，
以免阻塞唯一的共享 worker。

## 导出

PDF 始终为白底。PNG 优先使用 `ragg`，不可用时退回 Cairo；SVG 优先使用
`svglite`，不可用时退回 Cairo SVG。所有图形设备在异常路径上也会关闭，0 字节
文件会被拒绝。
