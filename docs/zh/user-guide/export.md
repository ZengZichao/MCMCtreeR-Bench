# 导出

## MCMCtree .tre

`.tre` 文件由带标定的树生成，而不是从参数表反推。它包含全部标定标签与完整树
结构。同一段文本会显示在预览块中，即使浏览器限制下载也可以复制。

## PDF

模块 A 为每个标定节点导出一页分布图。模块 B 将当前时间树导出为单页。PDF 使用
印刷主题，白底黑线。页面尺寸上限为 16 x 12 英寸。

## PNG 与 SVG

PNG 适合论文与幻灯片中的单图插入，上限为 12 x 9 英寸、200 dpi。SVG 是矢量
输出，便于后期编辑。PNG 与 SVG 使用导出面板的配色控件，默认印刷主题；如需当前
亮色或暗色界面配色，请选择 **跟随界面**。

## 下载行为

下载文件使用 ASCII 文件名，例如 `mcmctree_priors.tre`、
`node_distributions.pdf` 或 `time_tree.svg`。服务器写入会话工作区的临时文件，
关闭图形设备，确认文件非空后才发送。文件不会在会话之间保存。

## 结果失效保护

每次估计完成后，应用会对树、标定节点、年龄、分布与高级参数做一次哈希。任一
业务输入变化后，结果会被标记为过期，导出按钮被禁用，直到重新运行估计。语言与
主题切换不会使结果失效。
