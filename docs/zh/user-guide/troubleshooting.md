# 故障排查

## 树载入

- **提示树不是完全二分叉**：仍可尝试标定，但 MCMCtree 需要完全解析的树。导出前
  请解决多分叉。
- **没有分支长度**：模块 A 绘图仍可用；模块 B 的时间树绘图需要分支长度。
- **tip 名称重复**：请使 tip 名称唯一。重复 tip 的标定会产生歧义。
- **Nexus 文件包含多棵树**：只使用第一棵。如需其他树，请拆分文件。

## 标定与估计

- **导出被禁用**：上次运行后输入发生变化，或尚未运行。请重新运行估计。
- **节点无法估计**：检查最小值是否小于最大值，以及节点是否为内部节点。错误信息
  会包含节点编号。
- **`gamma` 的 alpha 不跟随设置**：本界面直接调用 `estimateGamma()`。上游
  `MCMCtreePhy()` 包装不遵守 `estimateAlpha = FALSE`，本界面不使用该路径。
- **已知 node.label 警告**：上游函数会产生 node.label 长度警告。该警告被归类为
  已知上游警告，不会使结果失效。

## 模块 B 数据源

- **MrBayes 文件被拒绝**：必须恰好有一个字面量 `.con.tre` 与匹配的 `.run1.t`。
  上传文件名会被保留，因为上游函数会从文件名推导同目录其他文件。
- **RevBayes 文件被拒绝**：请在同一次上传中提供一个 `.nex`/`.nexus` 与至少一个
  `.trees` 文件。
- **后验表没有 `t_n` 列**：chain 必须包含 `t_n1`、`t_n2` 等列。
- **User 节点年龄表不完整**：必须覆盖所有内部节点。上游 User 分支会索引全部
  节点，部分表会失败。
- **`distributions` 需要后验样本**：MCMCtree 使用后验表；User 使用节点年龄表。

## 下载

- **文件为空**：图形设备在成功与异常路径上都会关闭。若问题持续，请检查绘图状态
  信息，并用更小的画布重试。
- **浏览器阻止下载**：从预览块复制 `.tre` 文本。
- **PDF 能打开但空白**：改用印刷主题，并确认数据源已成功载入。

## 已知上游行为

- `nodeToPhy()` 写入较短的 `node.labels` 向量，`ape::write.tree()` 会把单个标签
  复制到所有节点。本界面会重建完整长度的标签向量，只有标定节点带标签。
- `MCMC.tree.plot()` 文档中的 `plot`/`pdfOutput` 参数并不存在。图形设备由本界面
  自己控制。
- `MCMC.tree.plot()` 把 `directory.files` 当作文件路径，而不是目录。

## 获取帮助

提交 GitHub Issue 时请附上输入类型、节点编号、完整错误文本，以及问题能否用
内置示例复现。请勿附上敏感数据。安全问题请按 `SECURITY.md` 私下报告。
