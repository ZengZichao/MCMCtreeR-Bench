# 模块 A：先验标定

模块 A 用于为 MCMCtree 准备时间先验。它采用六步导航，但步骤是状态导航器而不是
锁定式向导：已完成的步骤可以随时回退修改。

## 步骤 1：载入树

支持三种输入方式：

- 上传 `.tre`、`.nwk`、`.newick`、`.nexus`、`.nex` 或 `.txt` 文件；
- 粘贴 Newick 字符串；
- 载入 `MCMCtreeR` 的 `apeData` 示例。

树检查会报告 tips 数、内部节点数、分支长度、是否完全二分叉以及重复 tip 名称。
重复 tip 名称会被拒绝，因为标定会出现歧义。

## 步骤 2：选择标定节点

在常驻树预览中点击内部节点，或从列表中选择节点编号。再次点击已选节点会取消
选择。tip 不能作为标定节点；点击 tip 会显示说明。

每个已选节点都会显示后代物种，这是核对化石标定是否覆盖目标类群最直接的方法。

## 步骤 3：标定配置表

每行包含节点、tips 数、分布类型、最小/最大年龄以及实时校验状态。

| 分布类型 | 最小年龄 | 最大年龄 |
| --- | --- | --- |
| `cauchy` | 必填 | 必填 |
| `skewT` | 必填 | 必填 |
| `skewNormal` | 必填 | 必填 |
| `gamma` | 必填 | 必填 |
| `bound` | 必填 | 必填 |
| `upper` | 不使用 | 必填 |
| `fixed` | 必填 | 不使用 |

被禁用的字段会同时在状态中清空，隐藏值不会泄漏到导出文件。

## 步骤 4：高级参数

高级字段是可选的。留空即从上游调用中省略该参数，使界面默认值与上游默认值保持
一致。每个字段都有说明与范围校验；非法值会阻止估计。

`gamma` 通过 `estimateGamma()` 估计，因此 `estimateAlpha` 与 `estimateBeta`
会生效。上游 `MCMCtreePhy()` 包装在 `gamma`/`estimateAlpha` 上存在缺陷，本界面
不使用该路径。

## 步骤 5：运行估计

估计对每个节点调用一次 `estimateXxx()`。每个节点保存参数矩阵、节点标签、带
标定的树以及 MCMCtree 文本。树会用完整长度的 node label 向量重建，确保只有
标定节点带标签。

## 步骤 6：预览与导出

预览区显示带标定的树、完整 `.tre` 文本与参数汇总。可下载 `.tre` 文件，或导出
PDF/PNG/SVG 分布图。若上次运行后输入发生变化，导出会被禁用。

## .tre 文件包含什么

`.tre` 文本以 tips 数与一个 `1` 开头，随后是 MCMCtree 格式的树和
`//end of file`。每个标定以带引号的节点标签出现，例如
`'L(1.5,50,0.001,1e-300)'`、`'U(1.2,0.025)'` 或 `'=0.4'`。
