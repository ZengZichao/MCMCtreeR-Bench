# Citation

## GUI software

When you use this application, cite the GUI software entry:

```bibtex
@software{zeng2026mcmctreergui,
  author  = {Zeng, Zichao},
  title   = {{MCMCtreeR Bench}},
  version = {0.1.0},
  year    = {2026},
  url     = {https://github.com/ZengZichao/MCMCtreeR-Bench},
  note    = {R package version 0.1.0}
}
```

## Upstream paper

When you use the prior-calibration methods or the time-tree visualisation
approach, also cite the original paper:

```bibtex
@article{puttick2019mcmctreer,
  author  = {Puttick, Mark N.},
  title   = {{MCMCtreeR}: functions to prepare {MCMCtree} analyses and
             visualize posterior ages on trees},
  journal = {Bioinformatics},
  year    = {2019},
  volume  = {35},
  number  = {24},
  pages   = {5321--5322},
  doi     = {10.1093/bioinformatics/btz554}
}
```

The same two entries are available through `citation("mcmctreer")` and in
`CITATION.cff`. No DOI has been minted for the GUI in version 0.1.0.
